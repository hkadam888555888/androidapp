# My Adaptive Routine v1.0.3 — CI bootstrap candidate

This increment adds a GitHub Actions verification workflow and a guide for interpreting its results. The app remains a web/PWA source project; this package is not a native Android APK/AAB and is not production-verified.

## Changes
- Added `.github/workflows/verify.yml` for source audit, unit tests, coverage, lint, production build, dependency audit, and Chromium Playwright tests.
- Added `CI_VERIFICATION_GUIDE.md` describing the initial lockfile bootstrap and the limits of web CI evidence.
- Bumped visible/package app version to `1.0.3` and rotated the service-worker cache key to avoid stale cached shell assets.
- No IndexedDB record shape changes were intended; schema remains v9.

## Important limitation

A successful run must be triggered on GitHub in a network-enabled runner. This environment cannot access the npm registry, so no full dependency-backed test/build result is claimed. The workflow generates a `package-lock.json` artifact for review; after committing that lockfile, switch the install step to `npm ci` for reproducible installs.

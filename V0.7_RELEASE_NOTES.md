# My Adaptive Routine — v0.7.0

## Adaptation + Daily Review Increment

v0.7 closes the core feedback loop: explicit daily results can now teach the planner about real duration, useful time-of-day patterns, repeated skips, and roadmap pace.

### Delivered
- Rich daily review with actual-duration reporting, partial results, optional energy, reflection, and blocker notes.
- Explicit completed / partial / skipped task results remain auditable; the planner never infers completion.
- Persistent estimation profiles with original estimate, sample count, median actual duration, variance, learned estimate, and confidence.
- Gradual estimate adaptation; low-sample histories remain low-confidence and do not strongly change planner duration.
- Planner uses medium/high-confidence learned estimates for new roadmap scheduling.
- Persistent time-pattern profiles for morning / afternoon / evening success history.
- Planner can prefer a learned daypart when enough evidence exists, framed as a recent-history signal rather than a psychological claim.
- Repeated-skip detection with deterministic scope/split/move suggestions.
- Pace projection per active roadmap: AHEAD / ON_TRACK / AT_RISK / DELAYED, with projected completion explicitly labeled as an estimate.
- Persistent adaptation snapshots for roadmap pace history.
- Traceable planner overrides: move, lock, skip-today, duration, and priority controls are recorded; move/skip/duration/priority feed the deterministic planner.
- IndexedDB schema v7 with additive adaptation stores and v2-v7 backup compatibility.
- Updated Statistics and Daily Review screens to expose the learning loop.

### Verification boundary
- Strict TypeScript compilation of the pure domain/planner adaptation surface passed.
- Broader application source compilation passed with lightweight external-module stubs; third-party packages are not installed in this environment.
- Direct Node runtime checks for estimation learning, time-pattern learning, repeated-skip detection, and pace projection passed.
- Full npm test, Vite build, browser IndexedDB execution, and Playwright browser execution are not claimed as run here because the project dependencies/browser binaries are unavailable.

# My Adaptive Routine v1.0.2 — stabilization patch

## Important truth in the release label

This is a **web/PWA source stabilization archive**, not a production-verified Android APK/AAB. IndexedDB remains schema v9 because this patch does not change stored record shapes. The package version is 1.0.2; a lockfile could not be generated in this environment because npm registry access timed out.

## Defects addressed in source

- Prevent a plan regeneration from reusing a completed/reported daily-task ID as a fresh planned task. Pending blocks removed by regeneration are explicitly marked cancelled; reported history is preserved.
- Make plan generation read the latest persisted daily-task and plan rows in the same read-write transaction used to save the new plan, reducing stale-tab overwrite risk.
- Make task-result reporting re-read the authoritative task inside its transaction and reject a second report for completed, partial, skipped, cancelled, or rescheduled items.
- Make partial habit reporting use the saved habit configuration and commit habit log, task result, daily review, and audit row together.
- Fix the zero-value/zero-minimum case so no activity cannot count as a partial-success day.
- Make exercise logging read latest habit/task rows inside a single write transaction, preventing stale tabs from overwriting a previously recorded daily result. Validate the exercise date and bound the exercise-type label length.
- Save the Settings page's preferences, planner settings, AI settings, and audit entry in one transaction. Sanitize persisted/imported AI settings to local-only behavior and fail back to the deterministic provider on invalid local configuration.
- Precache the production JS/CSS shell assets for offline launches, reject incomplete JS/CSS bundle output, and allow the IPv6 loopback address in the restrictive CSP to match the local provider's endpoint policy.
- Pin TypeScript to the supported 6.0.x line so it is compatible with typescript-eslint 8.71.x, add Vite ambient type declarations, ESLint flat config, direct dependency version pins, test coverage thresholds, a gzip bundle budget, and a Playwright production-preview server. Add a local privacy/data-handling notice.

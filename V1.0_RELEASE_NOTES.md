# My Adaptive Routine v1.0.0

## Production-readiness increment

### First-run onboarding
- Three-step setup: roadmap, realistic schedule/capacity, and pre-save review.
- Compiles and validates the first curriculum before saving.
- Configures optional exercise and water habits.
- Explicit skip option; no roadmap is silently invented.
- A first-run marker is persisted in user preferences.

### Local model boundary
- Added `OpenAICompatibleLocalProvider` for a separately running local model server.
- Default remains the deterministic offline provider.
- Endpoint is restricted to loopback (`localhost`, `127.0.0.1`, `::1`); remote hosts, embedded credentials, and query-string tokens are rejected.
- Structured JSON responses are size-limited and parsed before use; provider task IDs are remapped inside the application boundary.
- No API key is stored by the app. This is an adapter, not a bundled model or guaranteed preconfigured runtime.

### Privacy, data, reliability
- Added opt-in browser notification delivery; it only runs while the app is open and the browser grants permission.
- Failed Notification API construction is never recorded as successful delivery.
- Backup imports validate the whole snapshot, row IDs, duplicate IDs, record count, store allowlist, and file size before opening the destructive transaction.
- Supports backup schema versions 2–9. Export uses schema 9 and app version 1.0.0.
- Added explicit type-to-confirm local data deletion; only safe empty first-run defaults remain after deletion.
- Removed automatic sample-habit seeding so deleting data does not repopulate habit records.
- Cached IndexedDB connection; closes on version change and resets the cache when open fails.
- Added skip link, focus-visible styling, reduced-motion CSS, mobile onboarding layout, and system health checks.
- IndexedDB schema bumped to v9 with additive preference/provider fields; historical rows are not rewritten.

## Verification boundary

- Source/parser checks and targeted domain tests should be run in a dependency-complete environment.
- This packaged environment did not include npm dependencies or browser binaries, so full `npm test`, `npm run build`, and Playwright E2E results are not claimed.
- Browser notification permission, local model CORS/endpoint, migration on real IndexedDB, backup restore, and destructive reset still require end-to-end testing in the target browser.

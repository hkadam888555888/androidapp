# My Adaptive Routine — v0.9.0 Release Notes

## AI Intelligence

This release adds the bounded AI layer described by the project specification.

### Roadmap understanding
- deterministic semantic analysis of parsed roadmap structure
- ambiguous learning-unit detection
- project/milestone signals
- instruction-like/prompt-injection-like text warning

### Scoped AI expansion
- expand one selected roadmap node at a time
- generate concept/task candidates
- validate task contracts and granularity
- validate proposed dependency graph
- filter duplicate/unsafe candidates
- record confidence and provider metadata
- preserve original roadmap text and history

### Practice + knowledge gaps
- generate optional practice prompts
- detect evidence of repeated difficulty from skips, partials, and confusion notes
- present suggestions rather than automatic failure labels

### Grounded explanations
- Planner can request an explanation from factual decision records
- raw chat/history is not sent to the explanation function
- explanation artifacts retain provider/version metadata

### Approval boundary
AI proposals are advisory by default. Explicit user approval creates a new curriculum version. Generated task and dependency IDs are remapped before persistence to prevent dangling references.

### Privacy/storage
- new `AIArtifact` store
- new `AISettings` store
- IndexedDB schema v8
- backup/import support through schema v8
- AI history retention toggle and deletion action

## Safety guarantees
AI cannot mark task completion, rewrite history, bypass planner validation, create impossible schedules, create dependency cycles, silently delete roadmap nodes, or convert uncertain suggestions into mandatory dependencies.

## Verification
- strict TypeScript compile: AI/domain surfaces passed
- source presence checks passed
- version metadata checked
- ZIP integrity checked
- full npm/Vite/Playwright runs not claimed because external dependencies/browser binaries are not installed in the available environment

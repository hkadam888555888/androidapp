# My Adaptive Routine v0.6.0

## Habit & Routine Engine
- First-class HabitLog persistence
- Daily/custom recurrence evaluation with editable due weekdays
- Active-from / active-until bounds
- Minimum-value policies and configurable streak semantics
- Explicit partial completion
- Streak policies and streak calculation (including weekly scheduled-day streaks)
- Weighted adherence metrics
- Exercise logging integrated with HabitLog and repeated logs accumulate safely
- Habit occurrence state: due/completed/partial/skipped/unreported/not_due
- Planner avoids scheduling already fulfilled recurring habits
- Recurrence-aware exercise, water, and custom habit reminder generation
- IndexedDB schema v6 migration
- JSON backup upgraded to schema/app version 6
- Habits UI upgraded with recurrence, minimum, adherence, and streak visibility

## Compatibility & safety
- Existing v0.5 habit records remain valid through optional/default fields.
- Historical task states are not rewritten.
- Missing logs remain unreported instead of being inferred as failure.
- Full npm/browser test suite is environment-dependent; targeted habit engine tests are included.
